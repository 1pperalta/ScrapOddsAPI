# AI Agent Tuning Skill

This skill guides the development and maintenance of the LangGraph-based AI agent to ensure high-quality outputs, cost-effectiveness, and architectural stability.

## Core Mandates

1. **Output Formatting & Predictability:**
   - **MUST** ensure all new or modified LLM prompts explicitly instruct the model to output data using the standard Markdown format expected by the frontend UI.
   - Required headers typically include: `## Resumen`, `## Mejores Opciones`, `## Justificacion`, `## Datos Usados`.
   - Discourage conversational filler from the AI (e.g., "Here is the analysis you requested...").

2. **Cost & Token Management:**
   - **NEVER** bypass or override the existing token limits or budget configurations set in the `.env` file (`BUDGET_LIMIT_USD`, `DAILY_LIMIT_USD`, `MAX_OUTPUT_TOKENS`).
   - **MUST** verify that the `budget_tracker` is invoked *before* any new LangGraph node or tool makes a request to OpenRouter or OpenAI.

3. **LangGraph Efficiency:**
   - Prioritize minimizing the number of distinct LLM calls within the graph.
   - Before adding new nodes, evaluate if the required processing can be accomplished by updating the prompt of an existing node or by executing a standard Python tool (deterministic logic) instead of an LLM.

4. **RAG Context Optimization:**
   - Ensure context passed to the LLM from ChromaDB is concise and relevant. Avoid stuffing the context window with raw JSON data; use the synthesized text narratives generated by `ContextBuilder`.

5. **Failure Handling:**
   - Design LangGraph edges to gracefully handle API timeouts, rate limits, or refused requests from the LLM provider, providing fallback paths or clear error states to the user.
